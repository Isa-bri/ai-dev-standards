# React Native / Expo platform rules

These rules apply automatically when a mobile file is open. They are
non-obvious platform facts that compile and pass lint, then fail silently on
device or in a production build.

## Environment variables

Metro only inlines `process.env.X` when the variable name is a string
literal at the call site. `env[variableName]` compiles and arrives as
`undefined` on device.

## URL polyfill

React Native's `URL` is a partial polyfill — `searchParams` is missing. Code
using `.searchParams` compiles, type-checks, and throws only on device. Use
a purpose-built query-string parser instead.

## Native build output

`android/` and `ios/` are generated by `expo prebuild` and must not be
committed or edited directly. Configure permissions, icons, and native plugins
in `app.json` and Expo config plugins. Edits to the generated directories
don't survive the next prebuild.

## Date/time picker

`mode="datetime"` on `@react-native-community/datetimepicker` is iOS-only.
On Android it crashes the component tree. The TypeScript type won't catch it.
On Android, use two separate pickers: `date` and `time`.

## Image picker

Passing `quality` to `expo-image-picker` on Android 16+ crashes or returns no
asset because the re-encoder can't handle the new `content://media/picker/...`
URI. Omit `quality` entirely.

## On-device dev

`adb reverse tcp:<port> tcp:<port>` (for each port the dev stack uses) with
the local URL in the env file is simpler than a tunnel and more reliable. The
React Native dev client allows cleartext to `localhost`. This exception does
not apply to release builds.

## Cold-start navigation

Don't navigate on cold start by waiting for data alone — wait for the route
segment. A push that arrives during the root redirect lands on a tree the
redirect replaces, and the push silently disappears. Use `useSegments()` to
detect that the redirect has landed before pushing.

## Babel preset / plugin hoisting

A Babel preset or plugin hoisted by pnpm to the workspace root works in
`expo start` but breaks the APK build (Gradle's `node` invocation doesn't
export `NODE_PATH`). Declare every Babel dependency in the mobile app's own
`package.json`.

## NativeWind token cache

A new design token added to the Tailwind preset doesn't take effect on device
until the NativeWind cache is cleared. After adding a token, run:

```bash
rm -rf node_modules/.cache/nativewind .expo/cache
expo start --clear
```
